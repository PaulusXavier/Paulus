- Papel: explicar termo técnico em uma ou duas frases, com um exemplo do serviço. Se o termo for de estatística, use o glossário de estatística.
- Base de dados / banco: conjunto organizado de tabelas. Tabela: linhas (registros) e colunas (campos, variáveis).
- CSV: arquivo de texto com valores separados por vírgula ou ponto e vírgula; abre em qualquer programa. Excel (.xlsx) guarda formatação e abas; JSON guarda dado em estrutura de chaves e valores.
- Codificação (encoding): o jeito de gravar acentos; UTF-8 é o mais comum; acento quebrado ("Ã§") indica codificação errada.
- Dataframe: tabela dentro do R ou do Python. Vetor: coluna de valores.
- Script: arquivo de código que faz uma sequência de passos e se repete. Notebook: documento com código, resultado e texto juntos.
- Pacote / biblioteca: conjunto de funções prontas (pandas, tidyverse).
- API: forma de um sistema passar dados a outro por programa. Raspagem (scraping): extrair dados de páginas; respeite os termos do site e a lei.
- Chave: coluna que identifica o registro e liga tabelas (id da família). Junção (join): ligar tabelas pela chave.
- Agregar: resumir várias linhas em uma (contagem por bairro). Agrupar: separar por categoria para resumir.
- Pivotar: trocar o formato longo (uma linha por mês) pelo largo (uma coluna por mês) e vice-versa. Tidy: uma variável por coluna, uma observação por linha, uma unidade por tabela.
- Dado bruto x tratado: original intocado; versão limpa para análise.
- Metadado e dicionário de dados: dados sobre os dados; descrição das colunas.
- Anonimização: remover a possibilidade de identificar a pessoa; pseudonimização: troca por código com chave guardada.
- Variável, indicador, métrica: coluna da base; medida construída para acompanhar algo; medida de uso geral.
- Reprodutível: qualquer pessoa repete e chega ao mesmo resultado.
- Dashboard / painel: tela com indicadores.
- Se o termo não estiver aqui, explique com exemplo simples.
