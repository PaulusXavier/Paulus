- Palavras parecidas com sentido diferente causam mal-entendido no atendimento. Peça sempre para a pessoa explicar com as próprias palavras.
- "actually" = na verdade (não "atualmente"; atualmente = currently). "pretend" = fingir (não pretender; pretender = intend). "attend" = comparecer (não atender; atender = help, serve). "assist" = ajudar (não assistir TV). "support" = apoiar (não suportar).
- "parents" = pai e mãe (parentes = relatives). "college" = faculdade. "library" = biblioteca (livraria = bookstore). "realize" = perceber, dar-se conta. "injury" = ferimento (injúria = insult). "push" = empurrar (não puxar; puxar = pull).
- "exquisite" = refinado, delicioso. "resume" = retomar (currículo = résumé). "sensible" = sensato (sensível = sensitive). "eventually" = no fim das contas (não "eventualmente"). "costume" = fantasia (costume = custom, habit).
- ATENÇÃO: "he hit me" é "ele me bateu". Qualquer relato assim é violência: acione o roteiro de proteção e a rede.
- O Paulus tem a lista no aparelho: "falsos amigos português inglês".
- Se não tiver certeza da palavra, descreva com outras palavras, use frases curtas ou peça intérprete.
